로그인 흐름 — 어떻게 구성할까요?

현재는 홈에서 LoginModal(팝업)이 뜨는 방식이에요. 새 로그인/회원가입 흐름을 어떻게 배치할지 선택해 주세요.

A

전용 로그인 페이지 /login

독립적인 /login 페이지를 만들고, 인증이 필요할 때 리다이렉트. 로그인 버튼 + 회원가입(Google로 시작) 버튼 모두 이 페이지에 표시.

모달 개선 + 전용 페이지 병행

앱 헤더의 로그인 버튼은 /login 페이지로 이동, 투표 시도 시에는 기존처럼 모달 표시. 두 진입점 모두 Google OAuth → 닉네임 설정 흐름으로 연결.
